# 电动汽车库房管理系统使用文档

## 一、系统概述

### 1.1 系统简介
本系统是专为电动汽车行业设计的库房管理系统，用于管理电动汽车相关零部件的库存。系统采用前后端分离架构，支持普通用户和库房管理员两种角色，提供零件查询、入库出库、库存记录追踪、补货提醒等核心功能。

### 1.2 主要功能
- **零件管理**：零件的增删改查、分类管理
- **库存操作**：零件入库、出库操作，自动记录操作历史
- **库存查询**：按关键词、分类等条件搜索零件
- **补货提醒**：自动识别库存低于预警值的零件
- **操作记录**：完整记录所有库存操作，支持按类型、分类查询
- **权限管理**：普通用户只能查看可见零件，管理员拥有全部权限

### 1.3 技术架构
| 层级 | 技术栈 |
|------|--------|
| 前端 | Vue 2.7 + Element UI + Vue Router + Axios |
| 后端 | Spring Boot 2.7 + Java 8 |
| 数据存储 | JSON文件持久化 |
| 开发工具 | Maven、npm |

## 三、系统安装与启动

### 3.1 后端启动步骤

**方式一：使用Maven命令启动**

1. 进入后端项目目录：
```bash
cd backend
```

2. 编译并启动项目：
```bash
mvn spring-boot:run
```

**方式二：打包后运行**

1. 打包项目：
```bash
mvn clean package
```

2. 运行打包后的jar文件：
```bash
java -jar target/ev-warehouse-1.0.0.jar
```

后端服务默认启动在 `http://localhost:8080`

### 3.2 前端启动步骤

1. 进入前端项目目录：
```bash
cd frontend
```

2. 安装依赖：
```bash
npm install
```

3. 启动开发服务器：
```bash
npm run dev
```

前端服务默认启动在 `http://localhost:8081`

### 3.3 访问系统
启动成功后，在浏览器中访问：
- **普通用户界面**：`http://localhost:8081/user/search`
- **管理员界面**：`http://localhost:8081/admin/parts`

## 四、普通用户使用指南

### 4.1 功能概览
普通用户可使用以下功能：
- 零件搜索与查询
- 库存操作（入库/出库）
- 查看库存记录
- 查看补货提醒

### 4.2 零件搜索

1. 进入用户搜索页面：`/user/search`
2. 在搜索框中输入关键词（零件编号或名称）
3. 可选择特定分类进行筛选
4. 点击"搜索"按钮查看结果

搜索结果展示以下信息：
- 零件编号、名称、分类
- 规格、库存数量、单位
- 库存状态（正常/需补货）

### 4.3 入库操作

1. 在搜索结果中找到需要入库的零件
2. 点击"入库"按钮
3. 在弹出的对话框中输入入库数量
4. 点击"确定"完成操作

**注意**：入库数量必须大于0

### 4.4 出库操作

1. 在搜索结果中找到需要出库的零件
2. 点击"出库"按钮
3. 在弹出的对话框中输入出库数量
4. 点击"确定"完成操作

**注意**：出库数量不能大于当前库存数量

### 4.5 查看库存记录

1. 进入记录页面：`/user/records`
2. 可按以下条件筛选：
   - 操作类型：全部/入库/出库
   - 分类：按零件分类筛选
3. 记录列表展示：
   - 记录编号、零件编号、零件名称
   - 操作类型、数量、单位
   - 操作前后库存、操作时间、操作人IP

### 4.6 补货提醒

系统会自动标记库存数量低于最低库存预警值的零件，状态显示为"需补货"。

## 五、管理员使用指南

### 5.1 功能概览
管理员除拥有普通用户的全部功能外，还可使用：
- 零件管理（新增、编辑、删除）
- 零件可见性设置
- 完整的库存管理权限

### 5.2 零件管理

**新增零件**：
1. 进入管理员库存管理页面：`/admin/parts`
2. 点击"新增零件"按钮
3. 填写零件信息：
   - 零件编号（唯一标识）
   - 零件名称
   - 分类（电池/电机/轮胎/控制器/玻璃/机油/其他）
   - 规格描述
   - 初始库存数量
   - 最低库存预警值
   - 计量单位
   - 是否对普通用户可见
4. 点击"确定"保存

**编辑零件**：
1. 在零件列表中找到需要编辑的零件
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"确定"保存

**删除零件**：
1. 在零件列表中找到需要删除的零件
2. 点击"删除"按钮
3. 在确认对话框中点击"确定"

**注意**：删除操作不可恢复，请谨慎操作

### 5.3 可见性设置

管理员可设置零件是否对普通用户可见：
1. 在零件列表中找到目标零件
2. 切换"可见性"开关
   - 开启：普通用户可见
   - 关闭：仅管理员可见
3. 系统会自动保存设置

### 5.4 补货提醒管理

管理员可在 `/admin/restock` 页面查看所有需要补货的零件，包括：
- 库存数量
- 最低库存预警值
- 缺口数量

## 六、数据说明

### 6.1 数据存储位置
系统数据以JSON文件格式存储在 `backend/data/` 目录下：
- `parts.json`：零件数据
- `records.json`：库存操作记录

### 6.2 零件数据结构
```json
{
  "id": "BAT-001",
  "name": "锂离子电池",
  "category": "电池",
  "specification": "50kWh",
  "quantity": 100,
  "minStock": 20,
  "unit": "块",
  "visible": true
}
```

字段说明：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 零件编号，唯一标识 |
| name | String | 零件名称 |
| category | String | 分类 |
| specification | String | 规格描述 |
| quantity | Integer | 当前库存数量 |
| minStock | Integer | 最低库存预警值 |
| unit | String | 计量单位 |
| visible | Boolean | 是否对用户可见 |

### 6.3 库存记录数据结构
```json
{
  "id": "REC-20240101120000-0001",
  "partId": "BAT-001",
  "partName": "锂离子电池",
  "category": "电池",
  "type": "入库",
  "quantity": 10,
  "unit": "块",
  "beforeQuantity": 90,
  "afterQuantity": 100,
  "ipAddress": "127.0.0.1",
  "createTime": "2024-01-01T12:00:00.000+0000"
}
```

### 6.4 示例数据
系统首次启动时会自动初始化示例数据，包含以下分类的零件：
- **电池类**：锂离子电池、磷酸铁锂电池
- **电机类**：永磁同步电机、异步电机
- **轮胎类**：子午线轮胎、防爆轮胎
- **控制器类**：整车控制器、电机控制器、电池管理系统
- **玻璃类**：前挡风玻璃、后挡风玻璃、侧窗玻璃
- **油类**：齿轮油、防冻液、刹车油

## 八、常见问题

### Q1: 如何修改后端服务端口？
修改 `backend/src/main/resources/application.properties` 中的 `server.port` 配置。

### Q2: 如何修改数据存储目录？
修改 `backend/src/main/resources/application.properties` 中的 `data.directory` 配置。

### Q3: 前端如何配置后端API地址？
修改 `frontend/vue.config.js` 中的代理配置，将 `target` 指向正确的后端地址。

### Q4: 数据会丢失吗？
系统会在每次数据变更后自动保存到JSON文件，正常关闭服务不会丢失数据。

### Q5: 如何重置数据？
删除 `backend/data/` 目录下的 `parts.json` 和 `records.json` 文件，重启系统后会重新初始化示例数据。
